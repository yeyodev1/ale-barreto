# Ale Barreto Studio — Web

Sitio de una sola página para Ale Barreto Studio (carpintería y diseño a medida). Solo frontend.

Stack: Vite + Vue 3 + TypeScript, GSAP ScrollTrigger, Lenis y Three.js.

```bash
npm install
npm run dev     # desarrollo
npm run build   # producción en dist/
```

Los datos de contacto (WhatsApp, correo, Instagram) están en `src/data/site.ts`.
